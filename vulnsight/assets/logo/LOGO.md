# VulnSight Brand Assets

## Logomark
- Dark backgrounds (#1e293b): reticle #f87171, target #fbbf24
- Light backgrounds: reticle #dc2626, target #d97706

## Files
- `vulnsight-logomark.svg` — mark only, transparent
- `vulnsight-logo-dark.svg` — full lockup for dark backgrounds
- `vulnsight-logo-light.svg` — full lockup for light backgrounds
- `vulnsight-favicon.svg` — simplified mark for browser tabs

## Usage
The mark must always appear with breathing room — minimum padding equal to 1/2 the mark's height. Don't recolor or distort.
